# Nexara 设置体系 SE 视觉语言全量改造计划

## 目标

以用户确认的修订方案 2 为视觉基线，将设置首页及其二级、三级、四级页面统一为 Solid Explorer 风格的安静、紧凑、扁平设置列表，同时保留 Nexara 的紫色品牌色与现有信息架构。

## 不可修改边界

- `MainTabScaffold` 的底部三按钮导航栏完全保持现状，包括外框、尺寸、间距、图标、文字与设置选中胶囊。
- 不修改设置业务逻辑、导航目的地、持久化协议、数据库结构和网络行为。
- 触控目标不低于 48dp；现有测试标签与可访问性语义保持稳定。

## 视觉契约

- 页面使用近黑背景与透明列表表面，不引入卡片堆叠或额外阴影。
- 分组标题使用小号、低对比紫色；组间用留白与细分隔线建立层级。
- 一级入口不设置前导图标列或装饰性尾随内容，所有主副标题形成单一垂直阅读轴；深层参数页只在功能确有需要时使用前导或尾随槽位。
- 一级入口使用 Material 3 双行列表：16sp/24sp 主标题和 14sp/20sp 功能副标题。副标题不承载动态状态；不显示箭头或账户编辑图标。账户身份头部不复用普通设置行，使用 56dp 头像与更高一级用户名排版；二至四级页面按具体配置保留副标题、开关、数值或操作。
- 二至四级页面统一使用标准 Material 3 字体角色：22sp 页面标题、16sp 设置主标题、14sp 辅助说明与分组标题；不再额外压缩为 10–14sp。TopAppBar、页面边距、分组节奏与控件对齐保持一致。

## 页面范围

1. 一级：首页账户、通用、AI 与模型、知识与检索、工具与数据、关于。
2. 二级：外观、提供商、默认模型、记忆设置、检索设置、工具设置、用量管理、备份、本地模型、开发者入口。
3. 三级：提供商编辑、提供商模型、知识图谱高级配置、RAG 调试及工具内配置面板。
4. 四级：模型编辑、提示词编辑、知识图谱与同一设置链路内的深层编辑界面。

## 实施顺序

1. 建立设置专用页面骨架、分组、列表行、开关行与视觉 token。
2. 迁移一级设置首页并锁定底部导航不变。
3. 按设置包、RAG 设置链路迁移二至四级页面。
4. 更新契约测试和截图基线，覆盖深色首页、外观页及代表性深层页面。
5. 执行定向单测、完整 JVM 测试、Lint、Debug/Release 编译和视觉对比。

## 验收标准

- 设置链路所有页面视觉语言一致，不再混用旧式卡片、宽松列表和不一致分组标题。
- 现有底部导航截图与交互实现没有代码改动和视觉漂移。
- 大字体、横屏和长文本仍可用，无裁切、遮挡或无限约束问题。
- `design-qa.md` 的最终结果为 `passed`，且记录参考图、实现截图与比较历史。
- DIA 与 HLG 按项目治理规则完成收口。
